title: Install Arakun

## Run the installer

```sh tab="macOS and Linux"
curl -fsSL {site.installUrl} | sh
```

```powershell tab="Windows"
irm {site.installUrl}.ps1 | iex
```

On macOS and Linux, run it in a terminal. It works on macOS with Apple silicon and on Linux x86_64. On Windows, run it in PowerShell.

## What the script does

It downloads the latest release, checks it against `SHA256SUMS` and installs it for your user.

| Platform | Installs to | To uninstall |
| --- | --- | --- |
| macOS | `~/Applications/Arakun.app`, linked as `~/.local/bin/arakun` | `rm -rf ~/Applications/Arakun.app ~/.local/bin/arakun` |
| Linux | `~/.local/bin/arakun` | `rm ~/.local/bin/arakun` |
| Windows | `%LOCALAPPDATA%\Programs\Arakun`, added to your user `PATH`, with a Start menu shortcut | Delete that folder and the shortcut, and remove it from `PATH` |

## A given version

```sh
curl -fsSL {site.installUrl} | sh -s -- --version v{site.version}
```

Or set `ARAKUN_VERSION=v{site.version}`.

<Callout type="warn">
  There is no build for Intel Macs or Linux on ARM yet. [Build from source]({site.sourceUrl}) there.
</Callout>

## Only the server

On a Linux x86_64 machine with no display, such as a VPS, install `arakun-server` alone. It needs glibc 2.35 or newer and none of the desktop libraries. See [Server](/docs/server). On other architectures, [build it from source]({site.sourceUrl}).

```sh
curl -fsSL {site.installServerUrl} | sh
```

## What Linux needs

glibc 2.35 or newer (Ubuntu 22.04+, Debian 12+, Fedora 36+), a Vulkan driver and the usual desktop libraries: libxkbcommon, Wayland or X11, fontconfig and freetype.

## Agents come separately

Arakun does not bundle the agents. Install the ones you want to use. Each agent's page in these docs says what it needs.
