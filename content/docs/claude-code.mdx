Arakun runs Claude Code through the ACP adapter `@agentclientprotocol/claude-agent-acp`.

## What you need

- Node.js with `npm`. Arakun installs the adapter itself.
- A `claude` that is signed in, or set up with an API key or another endpoint (`ANTHROPIC_BASE_URL`) in `~/.claude/settings.json` or the environment.

## Good to know

The Usage tab reads token use and cost from Claude Code's own logs, and shows your plan's limits.
