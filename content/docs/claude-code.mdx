Arakun runs Claude Code through the ACP adapter `@agentclientprotocol/claude-agent-acp`. The adapter brings its own Claude Code, so you don't have to install the `claude` CLI.

## What you need

Node.js with `npm`, from [nodejs.org](https://nodejs.org). Arakun uses it once, to install the adapter.

The first Claude Code session asks before it installs the adapter. It shows the package, the folder and the npm command. Click **Install**, or run the command yourself and click **Retry**. The adapter goes in `~/.local/share/arakun/agents`, or `%LOCALAPPDATA%\arakun\agents` on Windows. After that, Arakun updates it to the version it was built with, without asking.

The adapter runs the Claude Code binary that comes with it, so its version can differ from the `claude` in your terminal. It uses the `claude` on your `PATH` only when its own is missing. `CLAUDE_CODE_EXECUTABLE` picks another binary.

## Sign in

Claude Code runs on one of these:

- **Your claude.ai plan.** Open Settings › Claude Code and click **Sign in**, or press <kbd>Ctrl+K</kbd> and pick **Sign in to Claude Code**. A terminal runs `claude /login`; approve the sign-in in the browser. If you already signed in to `claude` in a terminal, Arakun finds it in `~/.claude` and you're done.
- **An API key or another endpoint.** Set `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN` or `ANTHROPIC_BASE_URL` in `~/.claude/settings.json` or the environment. Amazon Bedrock, Google Vertex AI and Microsoft Foundry work through Claude Code's own settings too.

Settings › Claude Code shows which one is in use, and your plan's limits. Arakun has no account of its own. It reads what Claude Code saves, sends it only to api.anthropic.com, and never changes it.

## Your settings carry over

The adapter loads your user, project and local settings. Your skills, hooks, plugins, MCP servers, `CLAUDE.md` and permission rules work as they do in the terminal. A new session starts in the permission mode set in `permissions.defaultMode`.

## Pick a model

The menu next to the composer lists the models, reasoning levels and modes Claude Code offers, plus a **Fast mode** switch. **Default (recommended)** shows which model it stands for. Arakun also adds Fable 5.2, which Claude Code can run but doesn't list yet. The environment remembers your pick for its next session.

The chip next to it sets the permission mode, Plan mode among them. In Plan mode you approve the plan before Claude Code starts.

## Usage

The Usage tab reads token use and cost from Claude Code's own logs, so sessions you run in a terminal count too. Signed in with a plan, it shows the 5-hour and weekly limits with their reset times. The session footer shows a limit as it fills up, and Arakun sends a desktop notification at 80% and when it is used up.

## What does not work yet

- Commands that only make sense in the terminal app are left out: `/clear`, `/cost`, `/keybindings-help`, `/login`, `/logout`, `/output-style:new`, `/release-notes`, `/todos` and others.
- The status line and keybindings from your settings don't apply in Arakun.
- With an API key or another endpoint there are no plan limits to show.
- [Headless agents](/docs/headless-agents) can't run Claude Code yet.

## Common errors

<Accordions>

<Accordion title="npm was not found">

Install Node.js, which includes npm, then click **Retry**.

</Accordion>

<Accordion title="Claude Code is not signed in">

Click **Sign in in a terminal** under the error, or run `claude` in a terminal and sign in with `/login`. Then click **Retry**.

</Accordion>

<Accordion title="Claude Code's own binary is missing">

An antivirus may have removed it. Allow the folder `~/.local/share/arakun/agents` (on Windows `%LOCALAPPDATA%\arakun\agents`) and restart Arakun. Or set `CLAUDE_CODE_EXECUTABLE` to a `claude` binary. The error names the log with the details.

</Accordion>

<Accordion title="Claude Code's 5h limit is used up">

The composer says when it resets, and offers to switch to Droid. Or sign in with a plan that has room, or use an API key.

</Accordion>

</Accordions>

## Use another adapter

`ARAKUN_CLAUDE_ACP` runs another adapter command instead of the one Arakun installs, and skips the install.
