---
title: Open pages and files
description: arakun browse, arakun open and arakun page.
---

## Open a page

```sh
arakun browse -s localhost:3000
```

This opens the page in the side pane.

## Open a file

```sh
arakun open -s src/main.rs:42
```

This opens the file in the side pane at line 42.

## Let an agent drive a page

Agents can drive pages on localhost through `arakun page`: screenshot, console, click, type and eval.

```sh
arakun page screenshot   # PNG of the environment's browser tab
```

## The browser is optional

<Callout type="warn">
  Browser tabs are based on CEF. Release builds do not include the browser yet. Build from source with the `browser` feature to get it.
</Callout>
