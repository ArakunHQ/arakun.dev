## Window

| Keys | What they do |
| --- | --- |
| <kbd>Ctrl+T</kbd> | New session |
| <kbd>Ctrl+J</kbd> | Toggle the terminal dock |
| <kbd>Ctrl+B</kbd> | Toggle the sidebar |
| <kbd>Ctrl+D</kbd>, <kbd>Ctrl+Shift+D</kbd> | Split right, split down |
| <kbd>Ctrl+Alt+arrows</kbd> | Move between panes |
| <kbd>Ctrl+Tab</kbd> or <kbd>Ctrl+1…9</kbd> | Switch tabs |
| <kbd>Alt+Up</kbd> and <kbd>Alt+Down</kbd> | Switch environments |
| <kbd>Ctrl+F</kbd> | Search the conversation |
| <kbd>Ctrl+=</kbd>, <kbd>Ctrl+-</kbd> and <kbd>Ctrl+0</kbd> | Zoom the whole interface |

## The palette

<kbd>Ctrl+K</kbd> or <kbd>Ctrl+P</kbd> opens the palette. One search covers sessions of every project, GitHub, runs, files and symbols, views, commands, settings and memory.

| Start with | To search |
| --- | --- |
| `>` | commands |
| `/` | files |
| `:` | settings |
| `@` | people |
| `#` | pull requests |

- <kbd>→</kbd> opens a row's actions or goes into it. <kbd>←</kbd> goes back.
- <kbd>Ctrl+Enter</kbd> asks an agent.

## The GitHub tab

| Keys | What they do |
| --- | --- |
| <kbd>J</kbd> and <kbd>K</kbd> | Next and previous item |
| <kbd>A</kbd> | Approve |
| <kbd>C</kbd> | Comment |
| <kbd>R</kbd> | Review with an agent |
| <kbd>O</kbd> | Open on GitHub |
